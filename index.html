    健康指引

    把重要的健康记录放在苹果「健康」App 里。第一次使用，只需要跟着下面的步骤操作。

    血压记录

    记录一次血压

    测量后，把收缩压（高压）和舒张压（低压）记录在苹果健康中。

    1. 在 iPhone 主屏幕上找到并打开「健康」App（白底红心图标）。
    2. 进入「浏览 / 搜索」，找到「心脏」→「血压」。不同系统版本显示可能略有不同。
    3. 选择「添加数据」，填写高压、低压和测量时间后保存。
    4. 以后在同一个页面查看历史记录和趋势。
    用药管理

    设置服药提醒

    第一次由本人根据医生或药师确认的药名、剂量、服药时间设置。

    1. 打开「健康」App，进入「浏览 / 搜索」→「用药」。
    2. 选择「添加药物」，按药盒和医嘱逐项填写药品信息与服药计划。
    3. 按需开启用药提醒；在系统设置中确认「健康」App 的通知权限。
    4. 实际服药后，可在苹果「健康」App 的用药页面标记已服药。
    本网页不会推荐药物、改变用药时间或建议补品。特别是甲状腺激素类药物，补充剂及饮食可能影响吸收，任何调整都应咨询医生或药师。

    找不到健康 App？

    从 iPhone 主屏幕向下轻扫，搜索「健康」。如果步骤与手机画面不同，可在健康 App 中用搜索查找「血压」或「用药」。普通网页不能直接读取 HealthKit，也不能确保一键跳转到指定的健康记录页面。

      我的设置

      网页中的设置、出差清单和工作台记录仅保存在当前设备的浏览器里。

      备份与恢复

      导出一份 JSON 备份文件，换手机或重新部署后，可以手动导入。备份包含网页设置、出差清单和全部工作台记录（含草稿和归档），不包含苹果健康 App 的任何医疗记录。

      添加到 iPhone 主屏幕

      ol class="steps">
    • 在 iPhone 的 Safari 浏览器中打开本助手。若从微信进入，可选择“在 Safari 中打开”。
    • 点击 Safari 的共享按钮（部分布局在页面菜单内），选择“添加到主屏幕”。
    • 如果出现“作为网页 App 打开”，将它开启；名称保留“随行小助手”，点击“添加”。
    • 回到主屏幕点击图标。若要迁移原记录，在这个入口中打开设置 → 导入备份，选择之前导出的 JSON 文件。
