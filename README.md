# 随行小助手

一个可添加到 iPhone 主屏幕的轻量网页工具，包含今日重点、交办跟进、随手记、工作提示词、健康指引与出差清单。

网页纯静态，不依赖外部字体或脚本。个人记录只保存在访问者自己的浏览器，不会自动上传到本仓库。工作提示词需复制给用户自行选择的 AI，本页不直接调用模型。

## 使用

在 Safari 打开已发布的网页，通过“共享 → 添加到主屏幕”安装。第一次保持联网，等待离线缓存准备好。不同设备、网址和浏览器的记录不会自动同步，迁移前请从设置导出 JSON，再在新入口导入。

## 备份

JSON 包含出差清单、工作记录、草稿及归档。Markdown 导出用于阅读。不要将个人备份、密码、密钥或公司非公开资料提交到本公开仓库。

GitHub Pages 从 main 分支根目录发布；`.nojekyll` 保留静态文件原样输出。离线功能依赖首次成功联网加载与设备浏览器支持。
